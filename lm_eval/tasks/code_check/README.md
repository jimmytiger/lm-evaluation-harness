# Python Code Quality Evaluation

## Overview

This task evaluates the quality of Python code generated by language models on simple programming problems. It goes beyond just functional correctness to assess various aspects of code quality including syntax validity, coding style, and best practices.

## Dataset

The task uses a custom dataset of 20 simple Python programming problems, each with:
- A clear problem statement
- Detailed description
- Test cases for validation
- Expected solution for reference

### Sample Problems

1. Calculate factorial of a number
2. Check if a string is a palindrome
3. Find maximum element in a list
4. Count vowels in a string
5. Reverse a list
6. Check if a number is prime
7. Calculate sum of digits
8. Remove duplicates from a list
9. Find second largest number
10. Check if two strings are anagrams
... and 10 more problems

## Metrics

The evaluation includes four comprehensive metrics:

### 1. Code Quality Score (Primary Metric)
A composite score (0-1) that combines:
- **Functional Correctness (50%)**: Syntax validity, execution success, and test pass rate
- **Code Quality (50%)**: Proper naming, documentation, complexity, error handling, and PEP8 compliance

### 2. Functional Correctness
Measures the percentage of test cases that pass when the generated code is executed.

### 3. Syntax Validity
Percentage of generated code samples that are syntactically valid Python.

### 4. Code Style Score
Evaluates adherence to Python coding best practices:
- Proper naming conventions (snake_case)
- Presence of comments or docstrings
- PEP8 basic compliance (line length)
- Reasonable complexity (cyclomatic complexity)

## Usage

### Running the Task

```bash
# Run the main code quality evaluation
lm_eval --model hf --model_args pretrained=your_model --tasks python_code_quality

# Run the entire code quality group
lm_eval --model hf --model_args pretrained=your_model --tasks code_quality
```

### Custom Metrics

The task implements several custom metrics in `utils.py`:
- `code_quality_score`: Comprehensive quality assessment
- `functional_correctness`: Test pass rate
- `syntax_validity`: Syntax correctness rate
- `code_style_score`: Style and best practices adherence

- Supports code blocks with ```python``` markers
- Automatic function detection
- Fallback to full text extraction
